# Neel 🎙️
### HandsFree CodeWriter

**Neel** is a browser-embedded, voice-controlled code editor designed to make JavaScript programming accessible and frictionless. By leveraging voice recognition, Neel allows users to dictate logic, execute scripts, and manage files without touching a keyboard—perfect for beginner-friendly exploration and accessible development.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🗣️ **Voice Commands** | Direct JavaScript dictation and editor control via natural speech. |
| 🚀 **Instant Execution** | Run your JavaScript code directly in the browser environment with one command. |
| 💾 **Local Export** | Save your spoken scripts directly to your desktop as `.js` files. |
| 🌐 **Zero Install** | Runs entirely in the browser using standard Web APIs. |

---

## 🚀 Quick Start

### 1. Launch the Editor
Open the [Neel Editor](https://bhav3shsingh.github.io/neel/) in any modern browser (Chrome or Edge recommended for best voice support).

### 2. Enable Microphone
Grant permission to use your microphone when prompted.

### 3. Speak Your Code
Try saying:
* *"Write: console.log('Hello World');"*
* *"Run program"*
* *"Save file"*

## 🛠️ Tech Stack & Engineering

Neel is built with a focus on **mechanical grit**—prioritizing functional, low-latency performance over abstract overhead.
* **Frontend:** HTML5, CSS3, JavaScript
* **Engine:** [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) for high-accuracy speech-to-text.
* **Architecture:** Event-driven command processing.
